# ⚡ Bash CLI Management & Automation Suite

![GNU Bash](https://img.shields.io/badge/Shell-GNU_Bash_4.3+-121011?style=for-the-badge&logo=gnu-bash&logoColor=white)
![Platform](https://img.shields.io/badge/OS-Linux_%7C_WSL_%7C_macOS-0078D6?style=for-the-badge&logo=linux&logoColor=white)
![Status](https://img.shields.io/badge/Status-Active-2EA44F?style=for-the-badge)

A structured collection of interactive, menu-driven command-line applications written in **GNU Bash**. Designed to demonstrate clean modular architecture, in-memory array management, reference passing, and automated data filtering without external dependencies.

---

## 🗂️ Project Directory

| ID | Project | Description | Key Bash Features |
| :--- | :--- | :--- | :--- |
| **01** | [**Student Result System**](./01-Student-Result-System) | Manages academic records, computes letter grades, performs case-insensitive lookups, and evaluates scholarship eligibility. | Parallel Arrays, Command Substitution, Parameter Expansion (`,,`), `case` Routing |
| **02** | [**Product Inventory System**](./02-Product-Inventory-System) | Tracks product catalog pricing, prevents duplicate entries, and filters items by minimum discount thresholds. | Nameref Pass-by-Reference (`local -n`), Dynamic Array Appending (`+=`), Arithmetic Evaluation |
